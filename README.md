Script d'automatisation et nettoyage de données EXCEL

Description :
- prends en entrée un fichier CSV d'une liste d'offres d'emploi (nom+ville+nb_abonnés_linkedin+poste+date)
- renvoie un fichier CSV propre sans doublon, sans erreur

Fonctionnalités :
- nettoie les doublons et les erreurs
- créé un nouveau CSV propre
- calculs simple sur classement des villes

Comment exécuter :
- pip install pandas
- input.csv dans le meme dossier
- executer sur python
